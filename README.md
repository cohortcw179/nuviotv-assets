# nuvio-assets

Cover images and GIFs for Nuvio app collections.
Served via GitHub raw URLs: `https://raw.githubusercontent.com/rrevanth/nuvio-assets/main/{category}/{name}/{name}-landscape.png`

## Naming Convention

```
{category}/{name}/
  {name}-landscape.jpg   # Landscape cover (16:9) - real photo
  {name}-landscape.png   # Landscape cover (16:9) - logo/art  
  {name}-landscape.gif   # Landscape cover (16:9) - animated (used as coverImageUrl)
  {name}-poster.png      # Poster format (2:3)
  {name}.gif             # Animated GIF (used as focusGifUrl)
```

> When a folder has both `-landscape.gif` and `.gif`:
> - `coverImageUrl` = `-landscape.gif`
> - `focusGifUrl` = `.gif`
>
> When a folder only has `-landscape.gif`:
> - `coverImageUrl` = `-landscape.gif` (no separate focusGif)
